## Notas para el copy

- **Maná = recurso de práctica con IA**: cada conversación/turno con el tutor consume maná; el plan define tu saldo mensual (el ritmo de avance por el currículo).
- **Estamento = sistema de prestigio interno** (NOBLE / REALEZA / DIVINO): el HUD muestra tu estatus; los nombres comerciales Plus/Pro/Max se usan para vender.
- **Expiración**: el maná no usado del mes se renueva en el ciclo; no se acumula.
- **Sub misiones**: al fallar una lección (<80% de metas), el Oráculo genera una sub misión de refuerzo (cuesta 100 maná).
