# Visión — Dungeon of English

> Documento maestro de visión. Sincronizado: 2026-07-30 (Fases 2-11).

## Propósito
**La mejor aplicación RPG educativa impulsada por IA** donde aprender un idioma es una aventura comparable a un videojuego AAA. Cada conversación es una "mazmorra", el progreso es de "cazador", y la práctica es una raid.

## Pilares
1. **Hablar desde el primer minuto**: pipeline de voz (record → STT Groq → LLM DeepSeek → TTS on-device) con latencia objetivo <1.5s.
2. **Progresión RPG**: CEFR como rangos (A1-C2), XP, rachas, niveles, títulos, battle pass.
3. **Gremio vivo**: el Gran Salón es el lobby MMORPG (NPC, quest board, mesas, prestigio).
4. **Economía sostenible**: gemas/oro/fragmentos/invocaciones con plan gratuito generoso ($0.02-0.05/mes/usuario de costo real) y premium por valor percibido.
5. **Motivación por misiones**: diarias, semanales, secretas, colaborativas, emergencias — con items que las modifican.
