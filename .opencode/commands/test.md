# Test

Ejecuta los tests del proyecto Flutter (20 archivos, 159 pruebas en la línea base del 25-oct-2026).

```sh
flutter test
```

- Loop rápido (reutiliza la dependencia resuelta, sin `pub get`): `flutter test --no-pub`.
- Equivalente al `--no-build`: reusa el build ya compilado, solo re-ejecuta los tests.
